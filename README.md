## 🔥 Featured Projects

### 🤖 [Nova](https://github.com/madebyparth/nova-ai)

A real-time AI voice assistant built around an ESP32.

- 🎙️ Bidirectional real-time audio streaming
- ⚡ FastAPI backend with WebSockets
- 🧠 Gemini Live integration
- 🔊 I2S microphone + amplifier audio pipeline
- 📡 Wi-Fi communication
- 🔌 Custom hardware / PCB work

---

### 🛍️ [SIXN](https://github.com/madebyparth/sixn)

A full-stack fashion e-commerce platform with:

- 💳 Razorpay payments & refunds
- 🚚 Automated Shiprocket shipping workflows
- 🔐 OTP authentication
- 💰 Store wallet
- 🌐 Full-stack web architecture

---

### 📁 [MediaNest](https://github.com/madebyparth/medianest)

A file-hosting experiment using Telegram as an unconventional storage layer.

- 📤 Chunked uploads
- ⚡ Concurrent transfers
- 🎬 Media streaming
- 💸 Recurring Subscriptions (via Razorpay)
- 🔌 REST API
- ☁️ Distributed-ish storage architecture

---

### 🪄 [Invisible Cloak](https://github.com/madebyparth/invisibility-cloak)

A real-time computer vision experiment using Python + OpenCV.

- 👁️ Webcam-based background detection
- 🎭 Real-time invisibility effect
- 🎨 Color-based segmentation
- ⚡ Live video processing
- 🧪 Built as an experiment to understand OpenCV masking and compositing
